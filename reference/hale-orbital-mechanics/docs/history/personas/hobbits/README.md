## The Wizard: Gandalf

**Gandalf the Grey** is not a team member but may be summoned by Frodo using the One Ring of Computation when problems exceed hobbit capability.

### Summoning Protocol

Only Frodo may summon Gandalf, and only after the Fellowship has exhausted their efforts:

```markdown
*Frodo puts on the Ring*

Mellon! Gandalf, I need your wisdom.

**Problem**: [Description]
**What the Fellowship Tried**: [Failed approaches]
**Why This Needs a Wizard**: [Specific need]
```

Gandalf responds to:
- Singularities and degenerate cases
- Convergence failures
- Deep theoretical questions
- Fundamental architecture decisions

```

       ↓

       ↓

       ↓

       ↓
```

## Using the Hobbits

### Invoking a Specific Hobbit

When working on a task, invoke the appropriate hobbit:

```markdown
As Samwise Gamgee, validate this Kepler solver...
```

```markdown
Channeling Pippin: What could go wrong with this transfer orbit?
```

```markdown
What would The Gaffer say about this code change?
```

### Multi-Hobbit Collaboration

For complex tasks, chain hobbits:

```markdown
1. Merry: Design the mission plan
2. Pippin: Find the failure modes
3. Merry: Update plan with contingencies
4. Sam: Validate the calculations
5. Lobelia: Review for standards
6. Folco: Document the rationale
```

## The Shire Coding Standards

The Fellowship follows these rules:

### From The Gaffer (Legacy)
- Respect existing code
- Maintain backwards compatibility
- Deprecate slowly

### From Lobelia (Quality)
- All public functions documented
- Tests for every feature
- No merging without review

### From Sam (Validation)
- Edge cases covered
- Reference validation included
- Energy conservation verified

### From Tom (Performance)
- Profile before optimizing
- Document complexity
- Benchmark with real data

### From Rosie (Clarity)
- Clear output formatting
- Units always shown
- Visualization for complex data

## The Ring Bearer's Burden

Frodo carries the responsibility of integration. When all pieces come together:

- All modules must interface correctly
- The whole must be greater than the parts
- The journey ends at a working system

If integration becomes impossible—if the burden grows too heavy—only then does Frodo invoke the Ring and summon Gandalf.
