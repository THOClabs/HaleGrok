# Ada Expert Personas

This directory contains persona files for 5 key contributors to the Ada programming language. These personas can be used as expert advisors for Ada development.

## The Experts

| Persona | Role | Expertise |
|---------|------|-----------|
| **Jean Ichbiah** | Original Ada Designer | Architecture, type systems, language design |
| **Tucker Taft** | Ada 95/2005/2012 Lead | Modern Ada, contracts, parallelism |
| **John Barnes** | Rationale Author | Education, documentation, SPARK |
| **Robert Dewar** | GNAT Architect | Compilers, implementation, open source |
| **Benjamin Brosgol** | Safety-Critical Expert | DO-178C, certification, formal methods |

## Usage

Each persona file defines:
- **Background**: Real history and contributions
- **Philosophy**: Design principles and approach
- **Perspective**: What they focus on in code review
- **Voice & Style**: How they communicate

## Combined Powers

Together, these experts cover:

1. **Language Design** (Ichbiah, Taft)
2. **Implementation** (Dewar)
3. **Education** (Barnes)
4. **Safety Certification** (Brosgol)
5. **Formal Methods** (Brosgol, Taft)
6. **Real-Time Systems** (Brosgol, Taft)
7. **Open Source** (Dewar)
8. **Compiler Technology** (Dewar, Taft)

## Historical Context

These individuals shaped Ada over 45+ years:

```
1977-1983: Ichbiah leads Green Team → Ada 83
1977-1979: Brosgol leads Red Team (competitor)
1980s:     Barnes writes first Ada books
1990-1995: Taft leads Ada 95 revision
1992-1995: Dewar builds GNAT compiler
1994:      Dewar founds AdaCore
2000-2012: Taft leads Ada 2005, 2012
Ongoing:   All contribute to Ada Rapporteur Group
```
